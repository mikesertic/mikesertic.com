# mikesertic.com

Personal site for Mike Sertic. Plain HTML and CSS, no framework, no build step. Hosted on Vercel.

## Run it locally

Any static server works. Clean URLs (`/about` instead of `/about.html`) come from `vercel.json`, so the closest match to production is the Vercel CLI:

```
npx vercel dev
```

Without an account, this is enough to preview pages (you will need to type the `.html` in the address bar):

```
python3 -m http.server 8000
```

## Deploy

Push to `main` on GitHub. Vercel builds and deploys automatically; there is nothing to compile. Redirects, clean URLs, and cache headers live in `vercel.json`.

Cloudflare sits in front of Vercel. Rocket Loader and Bot Fight Mode are switched on there and inject scripts into every page; both can be turned off in the Cloudflare dashboard with no effect on the site.

## Where things are

| What | Where |
|---|---|
| Pages | `index.html`, `about.html`, `work.html`, `speaking.html`, `press.html`, `newsletter.html`, `contact.html`, `404.html` |
| Styles | `styles.css` (design tokens are at the top) |
| Fonts | `fonts/` (self-hosted variable fonts: Cormorant Garamond, Libre Franklin) |
| Headshots | `headshot*.jpg` and `.webp` at the repo root |
| Open Graph images | `og/*.jpg`, generated by `scripts/build-og.sh` |
| Icons | `favicon.svg`, `icons/`, `site.webmanifest` |
| SEO | `sitemap.xml`, `robots.txt`, JSON-LD in each page's `<head>` |
| Analytics | Google Analytics 4 snippet in each page's `<head>` |

The header, nav, and footer are duplicated in every HTML file. When you change one, search and replace across all eight files.

## Common edits

**Add a podcast or talk.** Open `press.html` (and `speaking.html` for talks). Each list starts with a commented-out template entry. Copy it, fill it in, and place it in date order.

**Update a bio.** The three bios appear on both `about.html` and `press.html`. Change both.

**Turn on the newsletter form.** In `newsletter.html`, find the `SIGNUP FORM` comment. Create a form at your email provider (Kit's free plan is the suggested default), paste the form ID into the `action` URL, uncomment the form, and delete the "email me" fallback block beneath it.

**Regenerate share images.** Edit the text in `scripts/build-og.sh` or the layout in `scripts/og-template.html`, then run:

```
./scripts/build-og.sh
```

This uses the copy of Google Chrome installed on the Mac. No packages are needed.

**Add a headshot.** Drop the JPG at the root, make a WebP copy (`cwebp -q 82 in.jpg -o out.webp`), then add a `<figure>` to the headshot grid in `press.html`.

## Checks before publishing

- Run Lighthouse on the deployed preview URL. Targets are 90 or above in all four categories.
- Check that nothing in the copy uses an em dash or a placeholder marked `[VERIFY]` that has not been verified.
